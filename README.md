# OBSIDIAN-
OBSIDIAN es una plataforma de progreso personal diseñada para ayudarte a construir disciplina, registrar ejercicios, cumplir metas y medir tu evolución diaria. Con un diseño cyber-gótico azul neón, podrás organizar tus rutinas, usar temporizadores automáticos, monitorear estadísticas y ver tu progreso mes a mes en un solo lugar.
